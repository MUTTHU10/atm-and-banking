# Exp-1 ATM & BANKING SYSTEM

# AIM:
To develop a Software Requirements Specification (SRS) for an ATM and Banking System that allows users to perform banking operations such as cash withdrawal, cash deposit, balance enquiry, fund transfer, and mini statement securely and efficiently.

# SRS (Procedure):
1. Introduction: Identify the purpose and scope of the ATM and Banking System.

2. Problem Definition: Develop a system that provides easy and secure banking services to customers without visiting the bank.

3. Functional Requirements: Identify the main functions of the system:
- User authentication using ATM card and PIN.
- Cash withdrawal.
- Cash deposit.
- Balance enquiry.
- Fund transfer.
- Mini statement generation.
4. Non-Functional Requirements: Define system requirements such as security, reliability, performance, usability, and availability.

5. System Design: Prepare the necessary UML diagrams to represent the system structure and working.

6. Database Design: Identify the required data such as customer details, account details, PIN, and transaction records.

7. Testing: Verify that all banking operations work correctly and securely.

8. Documentation: Prepare the complete SRS document with all six diagrams.
